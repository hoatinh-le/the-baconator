    What this does

    Finds the shortest click path between two Wikipedia pages. It uses a bidirectional search: forward expands outgoing links, backward expands backlinks, with iterative deepening for shortest paths.

    Settings
    Depth ceiling
    Higher finds longer paths, but slower.
    Max links / backlinks
    Caps per page. Higher = more complete, slower.
    Concurrency
    Parallel requests. Too high can trigger rate limits.
    Filter hubs
    Skips “List of…”, years, disambiguation pages.
    Tips
    • If you see “No path found”, try raising caps before depth.
    • If it gets slow, lower concurrency to ~6–10.
    • Some pages have massive backlinks; caps matter a lot.
    About

    Data source: Wikipedia / MediaWiki API. This extension does not need your browsing history.
